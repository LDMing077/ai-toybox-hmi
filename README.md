# AI 玩具箱 HMI 交互原型

面向车机验证的静态网页交互原型，当前包含：

- AI 玩具箱首页及三个入口反馈
- 萌宠二级首页基础框架
- 全屏彩蛋二级页、气球字编辑键盘与完整预览动画
- 26 个英文字母、每个字母 4 种随机配色素材

## 本地预览

可直接打开 `index.html`，或在项目目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 路由

- `#/`：AI 玩具箱首页
- `#/pet`：萌宠页面
- `#/egg`：全屏彩蛋页面
- `#/sound`：个性音效首页（施工中状态）

## GitHub Pages 发布

项目不需要构建步骤，可直接将 `main` 分支的仓库根目录作为 Pages 发布源。所有资源均使用相对路径，页面放在仓库子路径下时也能正常加载；Hash 路由可直接刷新，不需要额外的 404 重写规则。

仓库根目录包含 `.nojekyll`，用于确保 Pages 原样发布静态资源。

## 当前范围

项目采用 2560×1440 设计基准并按容器等比缩放。个性音效目前为施工中首页；萌宠后续交互、说明内容与 Android WebView 封装将在后续阶段接入。
